はじめに

LOCLE営業ツールは「企業リサーチ → フォーム/メール送信 → CRM管理 → 反応分析」を一気通貫で自動化するツールです。

基本的な使い方の流れ：

  1. 企業リストに企業を登録する（手動・CSV・URL一括・自動検索）
  2. フォームを自動リサーチする（一括リサーチがおすすめです）
  3. メッセージ管理でバリアント（文面テンプレート）を作成する
  4. 送信管理から送信する（フォーム自動送信・メール送信・一括送信）
  5. CRMで商談・コンタクト・タスクを管理する
  6. レポート・分析で反応率を確認し、文面を改善する

ホーム画面の説明

ホーム画面（app.html）には、以下の5つのサマリーカードが表示されます。

  • 登録企業数：企業リストに登録されている企業の総数
  • 送信済み：フォーム・メールで送信済みの件数
  • 全体反応率：送信数に対する反応数の割合
  • 要フォローアップ：フォローアップ予定日が今日以前になっている企業の件数。0件のときは緑色、1件以上のときはオレンジ色で表示されます。
  • 期限切れタスク：CRMのタスクのうち、期限が今日以前かつ未完了のものの件数。0件のときは緑色、1件以上のときは赤色で表示されます。

サマリーカードの下には「今日のフォローアップ」一覧が表示され、企業リストページでアクションステータスを「フォローアップ予定」に設定し予定日が今日以前になっている企業が、企業名・次のアクション内容・予定日とともに一覧表示されます（対象がない場合は「今日のフォローアップはありません ✓」と表示されます）。

さらにその下には「未完了タスク」一覧が表示され、CRMのタスクタブに登録したタスクのうち期限が今日以前で未完了のものが、タスク内容・関連企業・期限とともに一覧表示されます（対象がない場合は「期限切れのタスクはありません ✓」と表示されます）。

企業リストページ

企業の追加方法

  • 手動追加：企業名・URL・メールアドレスを入力して「追加」ボタンをクリックします。
  • CSV一括インポート：name,url,email 形式の CSV ファイルを選択して「インポート」。1行目はヘッダー行、email 列は任意。既存 URL との重複はスキップされます。
  • URL一括貼り付け：テキストエリアに1行1URLで複数のURLを貼り付けて「一括追加」。企業名はURLのドメインから自動生成されます（例：https://example.co.jp → 企業名 example.co.jp）。Googleマップの検索結果ページやタウンページのURLは自動登録の対象外としてスキップされます。
  • 企業を自動検索：業種・都道府県・市区町村・キーワード・規模・上場区分・設立年数・売上規模・採用状況で条件を絞り込んで検索し、候補企業を一覧表示します。検索結果の各企業をチェックして、バリアントを選んでそのまま送信することもできます（自動送信モード / 手動確認モード / 登録のみモードから選択可能）。

いずれの方法で追加した場合も、登録後は自動でリサーチが開始されます。

自動リサーチの使い方

  • 個別リサーチ：各行の「リサーチする」ボタンをクリックすると、その企業だけリサーチします。
  • 一括リサーチ：「未リサーチを一括リサーチ」ボタンで、pending 状態の企業を順番に自動解析します。進捗バーと企業ごとの結果（✓成功 / ✕失敗 / 🔒CAPTCHA）がリアルタイムに表示されます。

メアド自動取得

リサーチ実行時、企業サイトから mailto リンクや本文中のメールアドレスを自動的に探し、info@ contact@ inquiry@ などの代表アドレスを優先して抽出します。企業にまだメールアドレスが登録されていない場合のみ自動で反映され、取得できた際は画面右上に通知（トースト）が表示されます。

営業お断り文言の自動検出

リサーチ実行時、企業サイトに「営業はお断り」「セールスはお断り」など営業拒否の文言が含まれていないかを自動チェックします。検出された場合はステータスが「🚫 営業お断り」になり、自動化は強制的にNGとなります。この企業へはフォーム自動送信・メール送信のどちらも自動的にスキップされます（設定タブで無効化することも可能です）。

ステータスの意味

ステータス意味
未リサーチまだ解析していない初期状態
✓ 完了フォーム解析が完了した状態
🔒 CAPTCHACAPTCHAが検出され自動送信できない
フォームなしお問い合わせフォームが見つからなかった
✕ エラー解析中にエラーが発生した
🚫 営業お断りサイトに営業お断りの文言が検出され、自動送信の対象外になった

詳細モーダルの「変更」ボタンから、これらのステータスは手動でも変更できます。

自動化 OK / NG の意味

  • OK：フォームへの自動入力・送信が可能です。送信管理ページで「フォームに自動送信」が使えます。
  • NG：フォームが見つからない・CAPTCHA がある・営業お断りが検出されたなどの理由で自動化できません。手動でコピー送信するか、メールアドレスを登録してメール送信を利用してください。

企業管理（検索・フィルター・優先度）

  • テキスト検索：企業名・URLを部分一致で検索します。
  • ステータスフィルター：未リサーチ / 完了 / CAPTCHA / フォームなし / エラー / 営業お断り で絞り込みます。
  • 自動化フィルター：自動化OK / 自動化NG で絞り込みます。
  • タグフィルター：登録済みのタグから選んで絞り込みます（企業に付けたタグをクリックしても同じフィルターが適用されます）。
  • アクションフィルター：アクションステータス（フォローアップ予定・商談設定済みなど）で絞り込みます。
  • 優先度：各行の ▲▼ ボタンで優先度（なし〜★★★）を設定できます。テーブルヘッダーの「優先度」をクリックすると、優先度の高い順・低い順に並び替えられます。

メモ・次のアクション・アクションステータス

  • 📝 メモ：各行の📝ボタンをクリックすると、行の下にメモ入力欄が展開されます。自由記述で記録し「保存」します。
  • 📌 次のアクション：各行のアクションボタンをクリックすると、アクションステータス（なし / フォローアップ予定 / 商談設定済み / お断り / 完了）・次のアクション内容・予定日を設定できます。設定済みの場合はボタンがカラーバッジで表示されます（フォローアップ予定＝黄、商談設定済み＝緑、お断り＝赤、完了＝グレー）。
  • アクションステータスを「フォローアップ予定」にして予定日を今日以前に設定すると、ホーム画面の「今日のフォローアップ」に表示されます。

企業タグ付け

各行の「詳細」ボタンからモーダルを開き、タグの追加・削除ができます。テキストを入力して「追加」、既存タグの「×」で削除し、最後に「保存」してください。設定したタグは企業名の下にpill形式で表示され、クリックするとそのタグで絞り込めます（業種・地域・規模などの分類に便利です）。

アーカイブと完全削除

  • 📦 アーカイブ：送信履歴を残したまま企業をリストから非表示にします。フィルターバーの「アーカイブ済みを表示」をチェックすると再表示でき、「元に戻す」でいつでも復元できます。
  • 🗑 削除：送信履歴がない企業はそのまま削除できます。送信履歴がある企業を削除しようとすると、アーカイブにするか、送信履歴・反応データごと完全削除するかを選ぶモーダルが表示されます。完全削除は取り消せません。

一括操作

  • 未リサーチを一括リサーチ：pending状態の企業を順番に自動解析します。
  • 一括送信：バリアント・対象企業（自動化OKのみ / メアド設定済みのみ / 両方）・チャネル（フォーム / メール / 自動判定）・強制送信の有無を選ぶと、対象企業数がプレビュー表示されます。「予約として登録」で送信予約（スケジュール）に一括登録するか、「今すぐ送信」で1社ずつ順番に送信できます。進捗はプログレスバーと結果リストでリアルタイムに確認できます。

メッセージ管理ページ

バリアントの作成方法

名前・チャネル（メール or フォーム）・件名（メールの場合）・本文を入力して「作成」ボタンをクリックします。

差し込み変数 {{company_name}}

本文テンプレートに {{company_name}} と書くと、送信時に企業名が自動で入ります。例：「{{company_name}} ご担当者様」→「株式会社○○ ご担当者様」

タグの使い方

key: value 形式でタグを任意に追加できます。分析ページでタグの key/value ごとに反応率を比較できるため、A/B テストの軸として活用できます。例：トーン: カジュアル、長さ: 短文

チャネルの違い

  • メール：Gmail OAuth 経由でメールアドレスに直接 DM 送信します。企業にメールアドレスが登録されている場合に使えます。
  • フォーム：ヘッドレスブラウザで企業サイトのお問い合わせフォームに自動入力して送信します。自動化 OK の企業のみ利用可能です。

バリアントのコピー

各カードの「コピー」ボタンをクリックすると、名前の末尾に「（コピー）」が付いた複製が一覧の先頭に作成されます。似た文面を素早く作りたいときに便利です。

送信前プレビュー

各カードの「プレビュー」ボタンから、企業名（デフォルト：株式会社サンプル）を入力欄で切り替えながら、{{company_name}} を実際の企業名に置き換えた件名・本文の見え方を確認できます。

送信管理ページ

下書き生成の手順

  1. 「企業」セレクトで送信先企業を選ぶ（★ マークはフォーム自動化 OK の企業）
  2. 「バリアント」セレクトで使用する文面テンプレートを選ぶ
  3. 「下書き生成」ボタンをクリックすると、{{company_name}} が企業名に置き換わったプレビューが表示される

文面スコア

下書きプレビューの下に、文字数・読みやすさスコア（0〜100）・改善ヒントが自動表示されます。読みやすさスコアは、1文の平均文字数・段落数・敬語表現・具体的な数字・{{company_name}} の使用有無から算出され、プログレスバーの色（緑・黄・赤）でひと目で確認できます。改善ヒントがない場合は「問題なし ✓」と表示されます。

送信方法

  • フォームに自動送信：ヘッドレスブラウザを使って企業サイトのフォームに自動入力して送信します。自動化 OK の企業にのみ表示されます。
  • メールで送信：Gmail OAuth 経由でメールを送信します。企業にメールアドレスが登録されている場合のみ表示されます。

いずれのボタンをクリックしても即座には送信されず、送信先企業名・チャネル・（メールの場合は）メールアドレス・件名/本文プレビュー・文面スコアを表示する確認モーダルが開きます。内容を確認してから「送信する」をクリックしてください。

スケジュール送信

下書きプレビューの「スケジュール送信」ボタンから、送信日時とチャネル（フォーム / メール）を指定して「予約する」と、送信予約として登録されます。登録した予約は「スケジュール一覧」セクションに企業名・バリアント名・予定日時とともに表示され、「削除」ボタンで取り消せます。

強制送信チェックボックス

同一企業への 24 時間以内の重複送信をスキップするチェックを無効にします。同じ企業に再送信したい場合はオンにしてください。

反応の記録・履歴の確認

送信履歴テーブルの「反応を記録」ボタンをクリックすると、分類（興味あり / 辞退 / 質問 / その他）と自由メモを入力できます。記録した反応は分析ページに反映されます。

送信履歴は企業名・ステータス（すべて / sent / failed / uncertain）・期間（すべて / 今日 / 今週 / 今月）でフィルターできます。「CSVエクスポート」ボタンから、フィルター後の送信履歴をCSVファイル（Excelでも文字化けしないBOM付きUTF-8）としてダウンロードできます。

CRMページ

CRMページ（crm.html）では、企業リサーチ・送信のあとの商談化・フォローアップを一元管理できます。7つのタブで構成されています。

1. パイプライン

商談をカンバン形式で管理します。ステージは「リード → コンタクト済み → 提案中 → 交渉中 → 成約 / 失注」の順で、カードをドラッグ&ドロップするだけでステージを変更できます。カンバンの上部には、パイプライン総額・成約数・成約率が集計表示されます。「+商談を追加」から企業・タイトル・金額・期待成約日を指定して新規商談を作成できます。

2. コンタクト

企業に紐づく担当者情報（名前・役職・メール・電話）を管理します。企業フィルターで絞り込みができ、メール・電話アイコンからそのまま連絡できます。

3. 活動履歴

電話・メール・メモ・商談・フォーム送信などのやり取りをタイムライン形式で記録します。種類ごとにアイコンと色が分かれており、いつ・どの企業と・どんなやり取りをしたかを時系列で確認できます。

4. 除外ドメイン

送信したくないドメインを登録しておくと、フォーム自動送信・メール送信の実行前に自動チェックされ、登録済みドメインの企業には送信されません（送信しようとするとエラーで拒否されます）。

5. タスク

期限付きのTODOを管理します。期限が今日以前で未完了のタスクは赤字で強調表示されます。チェックボックスで完了にでき、「完了済みを表示」をオンにすると完了済みタスクも一覧に表示されます。企業や商談に紐づけて登録することもできます。

6. A/Bテスト

2つのバリアントを比較して、送信数・反応数・反応率を横並びで確認できます。反応率が高い方に🏆勝者バッジが付き、両者の反応率の差から信頼度（高 / 中 / 低）が自動判定されます。

7. 設定

1日の送信上限・送信間隔・営業お断りサイトの自動スキップを設定します。詳しくは「設定」セクションをご覧ください。

レポートページ

レポートページ（reports.html）では、送信からパイプラインまでの成果をまとめて確認できます。分析ページの「詳細レポートはこちら」リンクからも移動できます。

  • 送信パフォーマンス：過去6ヶ月の月別送信数・反応数の推移を折れ線グラフで表示し、合計送信数・合計反応数・平均反応率をあわせて確認できます。
  • チャネル別内訳：フォーム送信とメール送信の件数比率をドーナツグラフと凡例で表示します。
  • バリアント別パフォーマンス：反応率が高い上位5件のバリアントを横棒グラフとテーブルで比較できます。
  • パイプライン価値：ステージ別の商談金額合計をグラフ表示し、合計パイプライン金額と期待成約額（提案中＋交渉中の合計）をカードで確認できます。
  • 月次トレンド：過去6ヶ月の成約・失注件数の推移を棒グラフで表示し、累計成約金額をカードで確認できます。

分析ページ

バリアント別集計の見方

各バリアント（文面テンプレート）ごとに送信数・反応数・興味あり数・反応率をグラフとテーブルで確認できます。反応率が高いバリアントが有効な文面です。

タグ別集計の見方

バリアントに設定したタグの key/value ごとの反応率をグラフとテーブルで比較できます。例：トーン・長さなどの軸で A/B テストの比較ができます。

改善ヒント

バリアント別集計の下に、以下のようなヒントが自動表示されます。

  • ✓ 最も反応率が高いバリアント：現時点で最も成果が出ている文面
  • △ 反応率が低いバリアント：送信数が3件以上あるバリアントの中で反応率が最も低いもの。文面の見直しの参考にしてください。
  • 💡 タグの傾向：タグ別の反応率差が10ポイント以上ある場合に、反応率が高いタグの組み合わせを提示します。
  • 💡 データ不足の注意：送信数の合計が5件未満の場合に表示されます。10件以上送信すると、より正確な分析ができます。

返信の自動取得

「返信チェック」ボタンをクリックすると、Gmail の未読メールを確認して送信履歴と照合し、返信があった場合に自動で反応を記録します。毎日ツールを使い始める前に押すのがおすすめです（毎朝 9 時にも自動実行されます）。

詳細レポートへのリンク

ページ上部の「詳細レポートはこちら」リンクと、サマリーカードの下にある月別送信数の簡易グラフから、より詳しい集計が見られるレポートページに移動できます。

設定

CRMページの「設定」タブ（crm.html → ⚙️ 設定）から、送信に関する以下の項目を調整できます。変更後は「保存」ボタンを押してください。保存すると画面右上に「設定を保存しました」という通知が表示されます。

  • 1日の送信上限：1日にフォーム・メールを合わせて送信できる件数の上限です（デフォルト20件）。この件数に達すると、それ以降の送信は「本日の送信上限(N件)に達しました」というエラーで拒否されます。
  • 送信間隔（秒）：連続送信する際の間隔の目安です（デフォルト30秒）。
  • 営業お断りサイトを自動スキップ：オンにすると、営業お断りの文言が検出された企業へのフォーム自動送信・メール送信を自動的に拒否します（デフォルトON）。

これらの設定は送信APIの内部でチェックされるため、送信管理ページ・企業リストページ・CRMのどこから送信しても共通して適用されます。

よくある質問

フォーム自動送信が「エラー」や「uncertain」になる

相手サイトのフォーム構造が複雑な場合があります。手動送信に切り替えてください。

「🚫 営業お断り」と表示される

企業サイトに営業お断りの文言が検出されました。このサイトへの自動送信は行われません。

CAPTCHAとは？

自動送信を防ぐセキュリティ機能です。CAPTCHA付きのフォームは自動送信できません。メール送信に切り替えてください。

1日の送信上限に達した

CRM→設定ページから上限数を変更できます。デフォルトは20件です。

除外ドメインに登録した企業に誤って送信した

除外ドメインは送信前に自動チェックされます。除外ドメインに登録されている企業には送信できません。

A/Bテストの信頼度とは？

2つのバリアントの反応率の差が5%以上で「高」、2〜5%で「中」、2%未満で「低」と表示されます。データが少ない場合は信頼度が低くなります。

スケジュール送信が自動で実行されない

現在、スケジュール送信の自動実行はVercel Proプランが必要です。手動で送信管理ページから送信してください。

アーカイブと削除の違いは？

アーカイブは送信履歴を残したまま企業をリストから非表示にします。削除は送信履歴ごと完全に消えます。
