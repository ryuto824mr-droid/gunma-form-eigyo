# locle の文面の下書き(全国向け)

【ここに記入】の箇所を埋めてから、送信管理の画面で文面(バリアント)として登録する。

- 宛名は `{{company_name}}` だけが使える。宛名が不確かな会社では、自動で次のように置き換わる(lib/greeting-name.js)。
  - 本文の「`{{company_name}} ご担当者様`」→「ご担当者様」
  - 件名の「`{{company_name}} 様|…`」→「…」
  - そのため、**本文の1行目と件名の形は変えない**。
- 全国に送るため「群馬の」「地元の」のような、相手が群馬県にいる前提の言い方はしない。拠点が群馬県であることは書いてよい。
- 実績・数字は事実だけを書く(誇大な表現・作った実績は書かない)。
- 連絡先は、フォームでは入力欄(送信者の情報)にも入る。本文の署名にも書く。

貴社のホームページを拝見し、今後の人材の採用や情報発信のお役に立てるのではないかと思い、ご連絡いたしました。

弊社では、【ここに記入: サービスを一言で。例「求人ページ・SNS・動画による採用と広報の発信」】を、企画から制作・運用までまとめてお引き受けしております。
【ここに記入: 何ができるか。例「採用サイトの制作、Instagram・TikTok の運用代行、社員インタビュー動画の撮影」】に対応しており、【ここに記入: 事実の実績。例「これまでに製造業・建設業を中心に◯社をご支援しました」】。

ご興味をお持ちいただけましたら、本フォームへのご返信、または下記の連絡先までお気軽にご連絡ください。

### メールで必ず残すもの

営業のメール(特定電子メール法)では、次の4つを本文に書く必要がある。署名と最後の段落を消さない。
1. 送信者の名前(会社名)
2. 住所
3. 苦情・問い合わせを受け付ける連絡先(電話・メール)
4. 今後のメールを断る方法(「不要」と返信)
